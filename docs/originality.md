# Original implementation record

SoFinder is an independent implementation based on ordinary file-management
requirements and public web platform, PHP, Symfony, and CKEditor integration
contracts.

The repository must not contain proprietary file-manager source code, compiled
scripts, stylesheets, images, icons, translations, product names, license keys,
or copied documentation. Contributions must be authored for SoFinder or come
from dependencies whose licenses are compatible with MIT distribution.

The initial visual system, React components, HTTP API, PHP contracts, local
storage adapter, and Symfony integration were authored specifically for this
project in August 2026. The implementation intentionally uses its own API and
does not claim wire-level compatibility with proprietary connector protocols.

Before a public release, maintainers should run a license scanner over source
and built assets, review dependency licenses, and perform a trademark search
for the product name.
