# 图片管理指南

服务器具备相应解码器时，SoFinder 将 JPEG、PNG、GIF、WebP、AVIF、BMP、ICO 视为浏览器图片。HEIC、HEIF、TIFF 可以作为普通文件保存，但不能预览、编辑或在图片选择器中选取。是否可用取决于真实内容、服务器能力和当前资源，而不只看扩展名。

## 上传与预览

图片使用普通文件的上传方式。发布前，SoFinder 会检查实际字节数、MIME、活动内容、解码尺寸和像素上限；扩展名与真实内容不一致会被拒绝。

选择图片后可查看大小、MIME、修改时间、路径和解码尺寸。右键选择**预览**可打开更大的缩略图。缩略图是私有缓存并带文件版本，不代表原图分辨率。

## 开启图片工具

进入**更多 → 设置 → 图片工具**，可开启缩放、裁剪、旋转和预设尺寸。这些是当前浏览器的显示偏好，只会显示按钮，不会增加服务器权限。格式不可编辑、资源只读或权限不足时，按钮仍会禁用。

## 旋转、缩放和预设

只选择一张可编辑图片：

- **向左／向右旋转**生成旋转 270° 或 90° 的新副本。
- **缩放**输入 `宽x高`，例如 `1200x800`；图片会按比例限制在该范围。
- 管理员配置的**预设**应用指定宽、高和质量，并生成新副本。

这些工具默认保留原图。SoFinder 自动选择不冲突的副本名，并报告最终名称和尺寸。

## 裁剪图片

点击**裁剪**打开编辑器：

1. 选择自由、原始比例、`1:1`、`4:3` 或 `16:9`。
2. 拖动图片，使用角点或边缘控制柄调整选区。
3. 调整缩放，或直接填写 X、Y、宽、高。
4. 方向键移动 1 像素，`Shift` + 方向键移动 10 像素。
5. 可撤销／重做（`Ctrl`／`Cmd` + `Z`，加 `Shift` 重做）、重置，并按住“比较”查看原图。
6. 以指定名称保存副本，或明确选择覆盖原图。

保存副本是安全默认值。覆盖会修改原路径，并要求独立的 `overwrite` 权限，不能由普通编辑权限推断。裁剪坐标必须在解码后的图片范围内。

## 动图和格式规则

资源决定允许保留还是拒绝动图。当编辑会静默丢失动画或多页内容时，SoFinder 会拒绝操作。输出保留原有受支持格式和扩展名；质量范围为 1–100，输出尺寸受资源及处理器限制。

## 向编辑器选择图片

图片选择器只允许返回具有可用入口 URL 且浏览器可嵌入的图片。选择图片后点击**选择**。公开资源可以返回 CDN URL；私有资源可能返回需要登录的 host route 或 proxy URL，宿主应用必须判断它是否适合文章的最终读者。

编解码要求参见[图片格式](/zh-CN/image-formats)，编辑器配置和使用参见 [CKEditor 4](/zh-CN/ckeditor4)。
