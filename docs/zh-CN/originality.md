# 原创实现纪录

SoFinder 是依据一般文件管理需求，以及公开 Web Platform、PHP、Symfony 与 CKEditor 整合契约所建立的独立实现。

Repository 不得包含专有文件管理器的原始码、编译后 Script、Stylesheet、图片、Icon、翻译、产品名称、License Key 或复制文件。Contribution 必须为 SoFinder 原创，或来自授权与 MIT 发布兼容的 Dependency。

最初的 Visual System、React Component、HTTP API、PHP Contract、本机 Storage Adapter 与 Symfony 整合，均于 2026 年 8 月专为本项目撰写。本实现刻意使用自有 API，且不宣称与专有 Connector Protocol 具 Wire-level 兼容性。

公开发布前，维护者应扫描原始码及 Build Asset 的授权、审查 Dependency License，并对产品名称进行商标搜索。
