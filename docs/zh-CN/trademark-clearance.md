# SoFinder 商标发布检查

这是工程发布关卡，不是法律意见。发布标签前，应记录附日期的查询结果：在 WIPO Global Brand Database、CNIPA、USPTO 与 EUIPO 搜索 `SoFinder`、`SO FINDER` 及容易混淆的相似名称。优先检查尼斯分类第 9 与 42 类，再补充检查第 35 与 38 类；另需搜索 GitHub、Packagist、npm，以及文件管理或 SaaS 领域持续存在的商业使用。

若软件、文件管理、SaaS 或线上服务领域存在相似的有效／申请中商标，或已有确立的商业使用，即视为阻挡冲突。此时不可自动改名，也不可发布；请保存证据，并由项目拥有者决定名称。不相关的家电或机械商标仍需记录，但不会自动阻挡发布。

## 2026-08-22 初步检查

- 准备期间查阅的 Packagist vendor 列表中，没有预定使用的 Composer vendor／package。
- 初步 Web 搜索结果显示一些不相关的家电用途，未确认有阻挡性的文件管理器或 SaaS 商标。
- 公开进行商业推广前，仍须正式查阅商标数据库并接受法律审查。除非触发阻挡冲突规则，软件包名称维持 `sohophp/sofinder`。

- USPTO 序号 97045626 使用 `SOFINDER`，用途是第 7 类家用清洁与厨房机械；此项记录为不相关商品类别，而非阻挡性的软件冲突。
- 搜索到 `sofinder.me` 社交个人资料链接应用程序；本次检查未发现其用于文件管理、具有相符的软件商标，或可能与此 PHP／Symfony 软件包造成来源混淆的证据。
- 发布前，公共 Packagist 与 npm registry endpoint 中均未出现 `sohophp/sofinder` 与 `@sohophp/sofinder-ui`。

工程关卡未确认任何阻挡冲突，因此 beta 保留项目名称。这不是法律上的商标核准意见；进行更广泛的商业推广前，仍需正式查阅数据库。
