# 文件管理器使用指南

本指南面向已经可以打开 SoFinder 的普通用户。管理员决定你可以访问哪些资源、文件类型和操作，因此只读资源或权限不足时，按钮可能隐藏或禁用。

## 认识操作界面

- 左侧的**资源**是相互独立的存储区，例如 Files、Images 或远程 S3 Bucket。
- 文件列表上方的**面包屑**显示当前文件夹，单击任意层级可返回。
- **搜索**默认按名称过滤当前文件夹；启用标签后可把范围改为“标签”，逗号分隔的多个条件必须全部匹配。
- **网格／列表**只改变显示方式，不会修改文件。
- **更多**菜单包含语言、排序、刷新、设置和回收站。
- 选择文件后，右侧**详细信息**显示类型、大小、位置、修改时间、图片尺寸和可用链接。

语言、视图、界面大小、左右面板宽度和可选功能会保存在当前浏览器中。“设置”分别为网格项目和列表行提供小、中、大三个受限档位。列表视图中可以拖动表头分隔线，在各列允许的最小和最大宽度内调整；双击分隔线会按该列内容自动适配，列宽同样保存在当前浏览器中。

## 浏览与选择

- 单击文件夹查看详情，双击进入；单击文件显示详情。
- 按住 `Ctrl`／`Cmd` 单击，可逐个加入或移出选择。
- 按住 `Shift` 单击，可连续选择一段文件。
- `Ctrl`／`Cmd` + `A` 选择或清除当前页全部项目，`Escape` 清除选择。
- 方向键移动选择，`Enter` 打开，`F2` 重命名，`Delete` 开始删除。
- 右键单击，或在触摸屏长按约半秒，可使用预览／打开、下载、重命名、复制、移动和删除。

选择范围只属于当前分页。批量操作前请确认选择数量。

## 新建文件夹和重命名

选择**新建文件夹**，输入名称后确认。按钮不可用通常表示资源只读、没有 `create_folder` 权限，或已经达到文件夹深度限制。

只选择一个项目后点击**重命名**，也可以按 `F2`。重命名文件时，扩展名会显示在输入框外，避免被意外修改。服务器仍会重新检查 Unicode 名称长度、扩展名、路径和权限。

名称不能以点号开头、以点号或空格结尾，不能包含控制字符、双向文本控制符或 `< > : " / \\ | ? *`，也不能使用 `CON`、`LPT1` 等 Windows 系统保留名。裁剪副本、复制／移动的自动改名以及回收站恢复都会执行相同检查。

## 上传文件

支持四种上传方式：

1. 点击**上传**并选择一个或多个文件；
2. 从桌面拖到 SoFinder 主区域；
3. 直接拖到某个文件夹，上传到该文件夹；
4. 在管理模式获得焦点时粘贴剪贴板中的图片或文件。

上传面板会显示排队、上传中、完成、失败和已取消状态，同时最多上传 3 个文件。大于 5 MB 的文件使用 4 MB 分块。页面中断后，在 24 小时内重新选择同一个本地文件即可续传。可以取消单个任务、取消全部、移除任务或清除已完成任务。

目标存在同名文件时，SoFinder 会询问是否覆盖，不会静默替换。失败原因可能包括 PHP／Web Server 限制、资源大小或配额、扩展名／MIME 禁止、活动脚本内容、无效图片、名称过长或权限不足；上传面板会保留服务器的具体错误。

## 复制与移动

选择一个或多个项目后点击**复制**或**移动**，在目标文件夹窗口中浏览并选择“复制到这里”或“移动到这里”。SoFinder 会阻止移动到当前父目录、把文件夹移动到自身或子目录，以及超出目标深度。

批量传输默认自动生成不冲突的名称。生成后的名称会重新检查目标资源的名称长度和扩展名策略。每个项目独立鉴权，完成提示会分别给出成功和失败数量。

## 下载和复制 URL

单个文件可从详细信息、预览窗口或右键菜单下载。私有 proxy 资源通过需要登录的 SoFinder URL 下载；公开资源可以返回配置的公开或 CDN URL。

在设置中启用**下载 ZIP**后，可选择多个文件或文件夹打包。ZIP 受到管理员配置的选择数量、递归项目数和总字节限制，服务器还必须安装 ZIP 支持。

**复制 URL**会打开实际入口地址。若弹窗提示需要登录，该地址不能当作公开分享链接。

## 删除与恢复

选择项目并点击**删除**，仔细阅读确认信息：

- 本地资源通常会移到用户隔离的私有回收站。
- 某些远程 Adapter 只支持永久删除，界面会明确警告无法恢复。
- 为满足项目数和容量限制，回收站可能自动清理最旧内容。

从**更多 → 回收站**可以搜索、查看到期时间和占用量、恢复或永久删除。原路径已有同名项目时，可选择自动改名或覆盖；覆盖需要独立权限。原父文件夹已不存在时，应先重新建立。

## 搜索、排序和个人元数据

名称搜索只针对当前文件夹，输入后会短暂延迟再请求。可按名称、大小、修改时间排序并切换升降序。远程 Adapter 不支持服务器搜索或排序时，对应控件会禁用。

分页栏可直接输入每页数量，也可从建议列表选择常用值。允许范围为每页 10–500 个文件；修改后会回到第一页，浏览器会记住该选择。

“设置”可以开启：

- **最近使用**：记录当前账号最近选择的路径。
- **收藏**：给一个项目加星标。
- **标签**：每个项目最多 10 个标签，每个 1–30 个可见字符；标签搜索用 `,` 或 `，` 分隔，所有条件都必须匹配。
- **文件夹树**、**下载 ZIP**、**回收站**等可选功能。

除非宿主应用替换策略，否则这些元数据按当前登录用户隔离。

## 管理模式与选择模式

管理模式提供新建、上传、重命名、复制、移动、删除和图片工具。CKEditor 等集成使用选择模式：选择一个文件后点击**选择**。文件夹、没有可用 URL 的文件不能返回；图片选择器还要求格式可直接嵌入浏览器。

图片操作请继续阅读[图片管理](/zh-CN/image-guide)，编辑器操作请阅读 [CKEditor 4 指南](/zh-CN/ckeditor4)。

## 文件夹上传、批量重命名与校验

**上传文件夹**会保留选择目录的相对结构，创建经过验证的父目录，遵守最大目录深度，每次最多选择 500 个文件。选中两个或更多项目后使用**批量重命名**，可先预览 `{name}`、`{n}`、`{ext}` 规则；扩展名保持锁定，每项结果分别报告。

预览支持图片以及有界的 UTF-8 文本、JSON、XML、YAML。预览详情可为不超过 512 MiB 的文件计算 SHA-256，传输校验时可选择并复制显示的值。

## 操作不可用时

常见原因包括资源只读、operation role 或 path ACL、Adapter 不支持、配额不足、文件夹过深、缺少 GD／Imagick，或当前处于选择模式。管理员更改权限后请刷新。向支持人员提供资源名、可见路径、操作和完整错误信息，但不要发送私有文件内容、凭据或签名 URL。
