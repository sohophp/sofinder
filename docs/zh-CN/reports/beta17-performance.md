# beta.17 性能报告

2026-08-27 在发布工作区使用 PHP 8.5.9 与 Node 22 测量。以下结果用于诊断，不是发布耗时门槛；beta.17 首轮刻意不采用易受环境影响的耗时硬限制。

| 场景 | 负载 | 本地结果 |
| --- | ---: | --- |
| 本地目录分页 | 10,000 个空文件、两个各 137 条的分页 | 在 6.16 秒组合测试内通过；峰值增长低于现有 128 MiB 防线 |
| 并发缩略图缓存 | 8 个 PHP 进程请求同一个 160×120 缩略图 | 通过；所有 Worker 正常退出且只留下一个有效 PNG |
| 上传队列渲染 | 100 个可独立操作的任务 | 在 22 项前端测试中通过（Vitest 3.14 秒） |
| S3 Cursor 分页 | MinIO 1,001 个对象，按 500/500/1 分页 | 由 `S3MinioIntegrationTest` 覆盖；最终耗时由固定版本的 MinIO CI Job 记录 |

发布报告同时记录 `sofinder.js` gzip 为 97,750 字节，低于初始入口 100 KiB 限制。后续 RC 应比较相同场景，在引入稳定耗时阈值前先调查性能回退。
