# SoFinder 商標發布檢查

這是工程發布關卡，不是法律意見。發布標籤前，應記錄附日期的查詢結果：在 WIPO Global Brand Database、CNIPA、USPTO 與 EUIPO 搜尋 `SoFinder`、`SO FINDER` 及容易混淆的相似名稱。優先檢查尼斯分類第 9 與 42 類，再補充檢查第 35 與 38 類；另需搜尋 GitHub、Packagist、npm，以及檔案管理或 SaaS 領域持續存在的商業使用。

若軟體、檔案管理、SaaS 或線上服務領域存在相似的有效／申請中商標，或已有確立的商業使用，即視為阻擋衝突。此時不可自動改名，也不可發布；請保存證據，並由專案擁有者決定名稱。不相關的家電或機械商標仍需記錄，但不會自動阻擋發布。

## 2026-08-22 初步檢查

- 準備期間查閱的 Packagist vendor 清單中，沒有預定使用的 Composer vendor／package。
- 初步 Web 搜尋結果顯示一些不相關的家電用途，未確認有阻擋性的檔案管理器或 SaaS 商標。
- 公開進行商業推廣前，仍須正式查閱商標資料庫並接受法律審查。除非觸發阻擋衝突規則，套件名稱維持 `sohophp/sofinder`。

## 2026-08-22 beta.2 工程複查

- 在 WIPO、USPTO、EUIPO 與 CNIPA 範圍執行精確名稱 Web 搜尋，未發現第 9、35、38 或 42 類中有效或申請中的檔案管理／軟體商標。
- USPTO 序號 97045626 使用 `SOFINDER`，用途是第 7 類家用清潔與廚房機械；此項記錄為不相關商品類別，而非阻擋性的軟體衝突。
- 搜尋到 `sofinder.me` 社交個人資料連結應用程式；本次檢查未發現其用於檔案管理、具有相符的軟體商標，或可能與此 PHP／Symfony 套件造成來源混淆的證據。
- 發布前，公共 Packagist 與 npm registry endpoint 中均未出現 `sohophp/sofinder` 與 `@sohophp/sofinder-ui`。

工程關卡未確認任何阻擋衝突，因此 beta 保留專案名稱。這不是法律上的商標核准意見；進行更廣泛的商業推廣前，仍需正式查閱資料庫。

## 2026-08-24 beta.9 工程複查

- 再次在 WIPO、USPTO、EUIPO 與 CNIPA 公開搜尋介面執行精確名稱查詢，並將第 9 與 42 類視為主要風險。
- 搜尋未發現會改變 beta.2 評估的新檔案管理或 SaaS 結果；USPTO 序號 97045626 仍是上述已記錄且不相關的第 7 類結果。

## 2026-08-25 beta.12 工程複查

- 針對 WIPO、USPTO、EUIPO 和 CNIPA 公共檢索頁面的同名搜尋，沒有在已索引結果中發現第 9、35、38 或 42 類檔案管理／軟體商標。
- USPTO 序號 97045626 仍為無關的第 7 類家用機械申請；97046433 為無關的第 11 類家電註冊。
- `sofinder.me` 仍是社交連結服務；近期汽車推廣把「SOFINDER」用作車輛配對功能，但沒有發現檔案管理產品、PHP 套件或開發工具的來源混淆。
- 發布檢查前，GitHub、Packagist 和 npm 公共搜尋沒有發現其他檔案管理軟體使用預定的 `sohophp/sofinder` 或 `@sohophp/sofinder-ui` 識別。

本次工程複查沒有發現阻止 beta.12 發布的軟體／檔案管理衝突，因此保留目前名稱。動態註冊系統和一般搜尋索引並不完整，本記錄不構成法律意見。
- 公開 Web 與套件 registry 搜尋未發現新近確立、容易混淆且足以要求停止發布的檔案管理套件或服務。

本次工程複查未發現阻擋衝突，因此 beta.9 可保留專案名稱。動態商標搜尋介面可能不會被一般 Web 索引完整收錄；此記錄不是法律上的商標核准意見，也不能取代更廣泛商業推廣前的正式資料庫查核或法律顧問審查。
