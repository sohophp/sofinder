# S3 相容儲存

S3 功能位於獨立套件，因此不會把 AWS SDK 加入核心安裝。

```bash
composer require sohophp/sofinder-s3:^0.1@beta
```

在 `config/bundles.php` 將 `SoFinderS3Bundle` 註冊於核心 Bundle 之後，再設定資源：

```yaml
so_finder:
  resources:
    RemoteAssets:
      adapter: s3
      root: media
      delivery_mode: proxy
      public_url: ''
      options:
        bucket: '%env(SOFINDER_S3_BUCKET)%'
        region: '%env(SOFINDER_S3_REGION)%'
        endpoint: '%env(SOFINDER_S3_ENDPOINT)%'
        use_path_style_endpoint: false
```

- AWS S3 不設定自訂 endpoint。
- Cloudflare R2 使用帳戶 endpoint 及 `region: auto`。
- MinIO 通常需要 path-style URL；只有受信任的開發網路才應允許 HTTP。
- 私有內容使用 `proxy` 並將 `public_url` 留空。
- SoFinder 不為 S3 提供本機回收站；需要復原能力時請啟用 Bucket Versioning。

完整供應商狀態、憑證規則及 smoke test 請參考[英文 S3 文件](/s3)。
