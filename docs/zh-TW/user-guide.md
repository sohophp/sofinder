# 檔案管理器使用指南

本指南面向已經可以開啟 SoFinder 的普通使用者。管理員決定你可以存取哪些資源、檔案類型和操作，因此只讀資源或權限不足時，按鈕可能隱藏或禁用。

## 認識操作介面

- 左側的**資源**是相互獨立的儲存區，例如 Files、Images 或遠端 S3 Bucket。
- 檔案列表上方的**麵包屑**顯示目前資料夾，點擊任意層級可返回。
- **搜尋**預設按名稱過濾目前資料夾；啟用標籤後可把範圍改為“標籤”，逗號分隔的多個條件必須全部匹配。
- **網格／列表**只改變顯示方式，不會修改檔案。
- **更多**選單包含語言、排序、重新整理、設定和回收站。
- 選擇檔案後，右側**詳細資訊**顯示類型、大小、位置、修改時間、圖片尺寸和可用連結。

語言、檢視、介面大小、左右面板寬度和可選功能會儲存在目前瀏覽器中。「設定」分別為網格項目與清單列提供小、中、大三個受限級距。清單檢視中可以拖曳表頭分隔線，在各欄允許的最小與最大寬度內調整；按兩下分隔線會依該欄內容自動調整，欄寬同樣儲存在目前瀏覽器中。

## 瀏覽與選擇

- 點擊資料夾檢視詳情，雙擊進入；點擊檔案顯示詳情。
- 按住 `Ctrl`／`Cmd` 點擊，可逐個加入或移出選擇。
- 按住 `Shift` 點擊，可連續選擇一段檔案。
- `Ctrl`／`Cmd` + `A` 選擇或清除目前頁全部項目，`Escape` 清除選擇。
- 方向鍵移動選擇，`Enter` 開啟，`F2` 重新命名，`Delete` 開始刪除。
- 右鍵點擊，或在觸控式螢幕長按約半秒，可使用預覽／開啟、下載、重新命名、複製、移動和刪除。

選擇範圍只屬於目前分頁。批次操作前請確認選擇數量。

## 新建資料夾和重新命名

選擇**新建資料夾**，輸入名稱後確認。按鈕不可用通常表示資源只讀、沒有 `create_folder` 權限，或已經達到資料夾深度限制。

只選擇一個項目後點擊**重新命名**，也可以按 `F2`。重新命名檔案時，副檔名會顯示在輸入框外，避免被意外修改。伺服器仍會重新檢查 Unicode 名稱長度、副檔名、路徑和權限。

名稱不能以點號開頭、以點號或空格結尾，不能包含控制字元、雙向文字控制符或 `< > : " / \\ | ? *`，也不能使用 `CON`、`LPT1` 等 Windows 系統保留名。裁切副本、複製／移動的自動改名以及資源回收筒還原都會執行相同檢查。

## 上傳檔案

支援四種上傳方式：

1. 點擊**上傳**並選擇一個或多個檔案；
2. 從桌面拖到 SoFinder 主區域；
3. 直接拖到某個資料夾，上傳到該資料夾；
4. 在管理模式獲得焦點時貼上剪貼簿中的圖片或檔案。

上傳面板會顯示排隊、上傳中、完成、失敗和已取消狀態，同時最多上傳 3 個檔案。大於 5 MB 的檔案使用 4 MB 分塊。頁面中斷後，在 24 小時內重新選擇同一個本地檔案即可續傳。可以取消單個任務、取消全部、移除任務或清除已完成任務。

目標存在同名檔案時，SoFinder 會詢問是否覆蓋，不會靜默替換。失敗原因可能包括 PHP／Web Server 限制、資源大小或配額、副檔名／MIME 禁止、活動指令碼內容、無效圖片、名稱過長或權限不足；上傳面板會保留伺服器的具體錯誤。

## 複製與移動

選擇一個或多個項目後點擊**複製**或**移動**，在目標資料夾視窗中瀏覽並選擇“複製到這裡”或“移動到這裡”。SoFinder 會阻止移動到目前父目錄、把資料夾移動到自身或子目錄，以及超出目標深度。

批次傳輸預設自動產生不衝突的名稱。產生後的名稱會重新檢查目標資源的名稱長度和副檔名策略。每個項目獨立授權，完成提示會分別給出成功和失敗數量。

## 下載與分享

單個檔案可從詳細資訊、預覽視窗或右鍵選單下載，下載會在新的瀏覽器分頁或視窗中開啟。私有 proxy 資源透過需要登入的 SoFinder URL 下載；公開資源可以返回設定的公開或 CDN URL。

在設定中啟用**下載 ZIP**後，可選擇多個檔案或資料夾打包。ZIP 受到管理員設定的選擇數量、遞迴項目數和總位元組限制，伺服器還必須安裝 ZIP 支援。

詳細資訊面板將入口簡化為**下載**和**分享**。分享視窗把**複製網址**與可選的 **QR Code** 放在一起。QR Code 在每位使用者的設定中預設關閉，完全在瀏覽器本機產生，不會把網址傳送給第三方 QR Code 服務。視窗會顯示登入要求和簽名網址失效時間；分享不會把私有網址變成公開網址。

## 刪除與恢復

選擇項目並點擊**刪除**，仔細閱讀確認資訊：

- 本地資源通常會移到使用者隔離的私有回收站。
- 某些遠端 Adapter 只支援永久刪除，介面會明確警告無法恢復。
- 為滿足項目數和容量限制，回收站可能自動清理最舊內容。

從**更多 → 回收站**可以搜尋、檢視到期時間和佔用量、恢復或永久刪除。原路徑已有同名項目時，可選擇自動改名或覆蓋；覆蓋需要獨立權限。原父資料夾已不存在時，應先重新建立。

## 搜尋、排序和個人後設資料

名稱搜尋只針對目前資料夾，輸入後會短暫延遲再請求。可按名稱、大小、類型、修改時間排序並切換升降序；「更多」選單也可依固定檔案類型篩選目前頁面，或按名稱、類型、大小、日期、標籤分組。遠端 Adapter 不支援伺服器搜尋或排序時，對應控制項會禁用。

分頁列可直接輸入每頁數量，也可從建議清單選擇常用值。允許範圍為每頁 10–500 個檔案；修改後會回到第一頁，瀏覽器會記住該選擇。

“設定”可以開啟：

**偏好方案**可以將目前工具、選用功能、清單欄位、網格/清單尺寸、資料夾導覽位置、快速存取範圍、介面大小及同名上傳策略儲存為命名方案。目前瀏覽器最多儲存 10 套；同名儲存會更新原方案，套用後立即更新介面。「還原系統預設」會重設完整偏好，包括面板和清單欄寬，與只修改版面的內建預設分開。

- **最近使用**：記錄目前帳號最近選擇的路徑。
- **收藏檔案**：僅為檔案加上星號，並在左側欄最多顯示 8 個連結；點選標題入口可進入具備搜尋、開啟定位和取消收藏功能的獨立頁面，網址使用 `collection=favorites`，支援瀏覽器上一頁/下一頁。
- **已固定資料夾**：與收藏獨立運作，只接受資料夾。預設彙整 Files、Images、Private 等全部根目錄，也可只顯示目前根目錄；失效資料夾會清楚標記，可開啟清理或用右鍵取消固定。側欄最多顯示 12 個資料夾。
- **側欄版面**：拖曳「已固定資料夾」「收藏檔案」「最近使用」或「資料夾導覽」上的六點控點，可在左右側欄之間移動，或調整同一側欄中的先後順序；版面會儲存在目前瀏覽器。聚焦控點後也可使用方向鍵操作。
- **標籤**：每個項目最多 10 個標籤，每個 1–30 個可見字元；標籤搜尋用 `,` 或 `，` 分隔，所有條件都必須匹配。
- **資料夾導覽**可依使用者設定放在左側或右側邊欄，此外還有**下載 ZIP**、**回收站**等選用功能。

除非宿主應用替換策略，否則這些後設資料按目前登入使用者隔離。

「選取」選單統一提供「全部選取、全部取消、反向選取」，操作範圍是目前篩選後可見的一頁。清單欄寬有上下限，可拖曳分隔線調整，按兩下自動適配；長文字會省略顯示，不會撐開版面。

## 管理模式與選擇模式

管理模式提供新建、上傳、重新命名、複製、移動、刪除和圖片工具。CKEditor 等整合使用選擇模式：選擇一個檔案後點擊**選擇**。資料夾、沒有可用 URL 的檔案不能返回；圖片選擇器還要求格式可直接嵌入瀏覽器。

圖片操作請繼續閱讀[圖片管理](/zh-TW/image-guide)，編輯器操作請閱讀 [CKEditor 4 指南](/zh-TW/ckeditor4)。

## 資料夾上傳、批次重新命名與校驗

**上傳資料夾**會保留所選目錄的相對結構，建立經過驗證的父資料夾，遵守最大目錄深度，每次最多選擇 500 個檔案。選取兩個或更多項目後使用**批次重新命名**，可先預覽 `{name}`、`{n}`、`{ext}` 規則；副檔名保持鎖定，每項結果分別回報。

預覽支援圖片以及有界的 UTF-8 文字、JSON、XML、YAML。預覽詳細資訊可為不超過 512 MiB 的檔案計算 SHA-256，傳輸校驗時可選取並複製顯示值。

## 操作不可用時

常見原因包括資源只讀、operation role 或 path ACL、Adapter 不支援、配額不足、資料夾過深、缺少 GD／Imagick，或目前處於選擇模式。管理員更改權限後請重新整理。向支援人員提供資源名、可見路徑、操作和完整錯誤資訊，但不要傳送私有檔案內容、憑據或簽名 URL。
