# CMS 內容編輯者指南

本指南面向在 CMS 中使用 SoFinder 的內容編輯、作者與網站營運人員，不要求瞭解 PHP 或伺服器。管理員會決定你能存取的儲存區與操作，因此實際介面可能比範例少一些按鈕。

## 先認識工作區

![顯示儲存區、圖片縮圖與檔案詳細資訊的 SoFinder 工作區](/screenshots/browser.png)

介面主要分為：

1. 左側的**儲存區**，例如「檔案」「Private」和「圖片」。請進入與目前內容用途一致的儲存區。
2. 中間的**資料夾和檔案**。按兩下資料夾進入，點選檔案查看詳細資訊。
3. 頂部的**搜尋、排序、檢視**。搜尋通常只針對目前資料夾。
4. 選取檔案後右側顯示**檔案詳細資訊**。使用前核對名稱、類型、大小、圖片尺寸與位置。
5. 工作區上方是**檔案操作**。系統只顯示目前帳號獲准使用的操作。

::: tip 上傳前
網站圖片應放入管理員指定的圖片區，下載資料應放入組織規定的文件區。除非組織政策明確允許，不要上傳密碼、客戶隱私資料或授權範圍不明的素材。
:::

## 上傳內容

1. 先開啟目標儲存區和資料夾。
2. 上傳一般檔案點選**上傳**；保留完整目錄結構時點選**上傳資料夾**。
3. 選擇本機檔案，上傳佇列運行期間不要關閉頁面。
4. 確認每一項都顯示**已完成**；失敗時閱讀該項的完整提示。
5. 選取剛上傳的檔案，檢查預覽、尺寸與所在位置。

也可以把檔案拖入主工作區；直接拖到資料夾上會上傳到該資料夾。同名檔案存在時：

- **自動改名**：保留兩個檔案，通常是最安全的選擇。
- **覆蓋**：僅在確實要替換舊檔案且擁有權限時使用。
- **略過**：保留舊檔案，不上傳目前檔案。

常見失敗原因包括格式不支援、檔案過大、配額不足、檔案損壞或不安全、權限不足。聯絡管理員時請提供儲存區、資料夾、檔名與完整錯誤資訊。

## 整理和尋找檔案

- 使用**新增資料夾**建立清晰結構，並遵守組織的命名規範。
- 只選一個項目後使用**重新命名**；副檔名會被單獨保護，避免意外修改格式。
- 選取項目後使用**複製**或**移動**，再選擇目標資料夾。
- 常用檔案可加入**收藏**，常用資料夾可固定到側欄。
- 已知檔名時按名稱搜尋；啟用標籤後，可依活動、主題或負責人尋找。
- **檢視**可切換圖片縮圖或精簡清單，不會修改檔案。

批次操作前務必確認已選取數量。選取範圍只包含目前可見頁，不會自動包含大型資料夾的其他分頁。

## 準備發布圖片

選取圖片後點選**圖片編輯**。如果沒有該按鈕，可在**更多操作 → 設定**中啟用相應圖片工具，或向管理員確認帳號權限和圖片格式是否支援編輯。

![包含裁剪控制與儲存選項的 SoFinder 圖片編輯器](/screenshots/image-editor.png)

建議採用以下流程：

1. 依 CMS 元件要求選擇 `16:9`、`4:3` 或 `1:1` 等裁剪比例。
2. 移動並調整裁剪框，確保主體與重要內容完整。
3. 只有 CMS 明確提供目標尺寸時，才輸入準確寬高。
4. 可用時使用**最佳化**減少檔案大小，並檢查預覽。
5. 預設保留**另存副本**；只有確定所有舊用途都應變更時才覆蓋原圖。
6. 為副本填寫有意義的名稱，儲存後選取新檔案。

不要為了達到尺寸而放大小圖，否則畫面會模糊。盡量不要把正文做進圖片；應在 CMS 或資產後設資料中填寫有意義的替代文字。純裝飾圖片應標記為裝飾，而不是編造替代文字。

## 把檔案插入 CMS 內容

CMS 以選擇器開啟 SoFinder 時：

1. 進入正確的儲存區和資料夾。
2. 選取一個檔案，檢查詳細資訊或預覽。
3. 圖片需確認裁剪、尺寸與檔名適合目前內容區塊。
4. 點選**選取**，SoFinder 會把檔案返回 CMS。
5. 回到 CMS 後，補充替代文字、說明、連結行為等內容欄位，再發布頁面。

私有檔案網址可能要求登入或會到期。除非管理員確認傳遞方式適合公開存取，否則不要把它用於公開文章、電子郵件或外部網站。

## 安全地替換、刪除與復原

如果舊圖片可能已經用於已發布頁面，優先用新檔名上傳新版本。覆蓋會影響所有引用同一網址的頁面，而且瀏覽器或 CDN 可能仍保留舊快取。

刪除時：

1. 核對檔名、資料夾和選取數量。
2. 閱讀資產使用提示；若已有頁面引用，應先更新這些頁面。
3. 確認視窗提示的是可復原刪除還是永久刪除。
4. 本機可復原檔案可從**資源回收筒**還原；原名稱已被占用時，除非明確要替換，否則選擇自動改名。

## 常見問題速查

| 問題 | 檢查內容 |
| --- | --- |
| 按鈕消失或不可用 | 儲存區可能唯讀、帳號無權執行、或選取模式限制了工具。 |
| 上傳失敗 | 閱讀佇列提示，並檢查格式、大小、檔名與配額。 |
| 無法編輯圖片 | 格式可能不支援、設定中未啟用工具、或伺服器缺少圖片解碼器。 |
| 檔案無法選取 | 可能選中了資料夾、選擇器要求圖片、或檔案沒有可用網址。 |
| 別人無法開啟分享連結 | 連結可能要求登入、已經到期、或屬於私有儲存區。 |
| 資源回收筒找不到檔案 | 該儲存可能永久刪除，或保留期限已經結束。 |
| 實際介面與指南不同 | 功能和文字取決於 CMS、帳號權限與管理員設定。 |

尋求支援時，請提供儲存區、可見資料夾、檔名、執行的操作與完整錯誤文字。不要傳送密碼、私有檔案內容或簽名網址。進階功能請見[完整檔案管理器指南](/zh-TW/user-guide)和[圖片管理](/zh-TW/image-guide)。
