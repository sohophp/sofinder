# beta.17 效能報告

2026-08-27 在發佈工作區使用 PHP 8.5.9 與 Node 22 測量。以下結果用於診斷，不是發佈耗時門檻；beta.17 首輪刻意不採用容易受環境影響的耗時硬限制。

| 場景 | 負載 | 本機結果 |
| --- | ---: | --- |
| 本機目錄分頁 | 10,000 個空檔案、兩個各 137 筆的分頁 | 在 6.16 秒組合測試內通過；峰值增長低於現有 128 MiB 防線 |
| 並行縮圖快取 | 8 個 PHP Process 請求同一個 160×120 縮圖 | 通過；所有 Worker 正常結束且只留下一個有效 PNG |
| 上傳佇列顯示 | 100 個可獨立操作的工作 | 在 22 項前端測試中通過（Vitest 3.14 秒） |
| S3 Cursor 分頁 | MinIO 1,001 個物件，按 500/500/1 分頁 | 由 `S3MinioIntegrationTest` 涵蓋；最終耗時由固定版本的 MinIO CI Job 記錄 |

發佈報告同時記錄 `sofinder.js` gzip 為 97,750 Bytes，低於初始入口 100 KiB 限制。後續 RC 應比較相同場景，在引入穩定耗時門檻前先調查效能回退。
