# 原創實作紀錄

SoFinder 是依據一般檔案管理需求，以及公開 Web Platform、PHP、Symfony 與 CKEditor 整合契約所建立的獨立實作。

Repository 不得包含專有檔案管理器的原始碼、編譯後 Script、Stylesheet、圖片、Icon、翻譯、產品名稱、License Key 或複製文件。Contribution 必須為 SoFinder 原創，或來自授權與 MIT 發布相容的 Dependency。

最初的 Visual System、React Component、HTTP API、PHP Contract、本機 Storage Adapter 與 Symfony 整合，均於 2026 年 8 月專為本專案撰寫。本實作刻意使用自有 API，且不宣稱與專有 Connector Protocol 具 Wire-level 相容性。

公開發布前，維護者應掃描原始碼及 Build Asset 的授權、審查 Dependency License，並對產品名稱進行商標搜尋。
