# 圖片管理指南

伺服器具備相應解碼器時，SoFinder 將 JPEG、PNG、GIF、WebP、AVIF、BMP、ICO 視為瀏覽器圖片。HEIC、HEIF、TIFF 可以作為普通檔案儲存，但不能預覽、編輯或在圖片選擇器中選取。是否可用取決於真實內容、伺服器能力和目前資源，而不只看副檔名。

## 上傳與預覽

圖片使用普通檔案的上傳方式。釋出前，SoFinder 會檢查實際位元組數、MIME、活動內容、解碼尺寸和畫素上限；副檔名與真實內容不一致會被拒絕。

選擇圖片後可檢視大小、MIME、修改時間、路徑和解碼尺寸。右鍵選擇**預覽**可開啟更大的縮圖。縮圖是私有快取並帶檔案版本，不代表原圖解析度。

## 開啟圖片工具

進入**更多 → 設定 → 圖片工具**，可開啟縮放、裁剪、旋轉和預設尺寸。這些是目前瀏覽器的顯示偏好，只會顯示按鈕，不會增加伺服器權限。格式不可編輯、資源只讀或權限不足時，按鈕仍會禁用。

## 旋轉、縮放和預設

只選擇一張可編輯圖片：

- **向左／向右旋轉**產生旋轉 270° 或 90° 的新副本。
- **縮放**輸入 `寬x高`，例如 `1200x800`；圖片會按比例限制在該範圍。
- 管理員設定的**預設**應用指定寬、高和品質，並產生新副本。

這些工具預設保留原圖。SoFinder 自動選擇不衝突的副本名，並報告最終名稱和尺寸。

## 裁剪圖片

點擊**裁剪**開啟編輯器：

1. 選擇自由、原始比例、`1:1`、`4:3` 或 `16:9`。
2. 拖動圖片，使用角點或邊緣控制柄調整選區。
3. 調整縮放，或直接填寫 X、Y、寬、高。
4. 方向鍵移動 1 畫素，`Shift` + 方向鍵移動 10 畫素。
5. 可撤銷／重做（`Ctrl`／`Cmd` + `Z`，加 `Shift` 重做）、重置，並按住“比較”檢視原圖。
6. 以指定名稱儲存副本，或明確選擇覆蓋原圖。

儲存副本是安全預設值。覆蓋會修改原路徑，並要求獨立的 `overwrite` 權限，不能由普通編輯權限推斷。裁剪座標必須在解碼後的圖片範圍內。

## 動圖和格式規則

資源決定允許保留還是拒絕動圖。當編輯會靜默丟失動畫或多頁內容時，SoFinder 會拒絕操作。輸出保留原有受支援格式和副檔名；品質範圍為 1–100，輸出尺寸受資源及處理器限制。

## 向編輯器選擇圖片

圖片選擇器只允許返回具有可用入口 URL 且瀏覽器可嵌入的圖片。選擇圖片後點擊**選擇**。公開資源可以返回 CDN URL；私有資源可能返回需要登入的 host route 或 proxy URL，宿主應用必須判斷它是否適合文章的最終讀者。

編解碼要求參見[圖片格式](/zh-TW/image-formats)，編輯器設定和使用參見 [CKEditor 4](/zh-TW/ckeditor4)。
